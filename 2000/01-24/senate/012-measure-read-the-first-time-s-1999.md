# MEASURE READ THE FIRST TIME--S. 1999

```
                  MEASURE READ THE FIRST TIME--S. 1999

  Mr. MACK. Mr. President, I send a bill to the desk and ask for its 
first reading.
  The PRESIDING OFFICER. The clerk will report.
  The legislative clerk read as follows:

       A bill (S. 1999) for the private relief of Elian Gonzalez 
     Brotons.

  Mr. MACK. Mr. President, I now ask for its second reading.

morning business.
```
