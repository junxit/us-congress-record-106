# MAKING IN ORDER CERTAIN MOTIONS TO SUSPEND THE RULES ON TODAY

**Speaking:** Morella, Constance A. (M000941) [R-MD]

**Measures:** H.R. 2302, H.R. 3454, H.R. 4448, H.R. 4449, H.R. 4484, H.R. 4534, H.R. 4615, H.R. 4884

```
     MAKING IN ORDER CERTAIN MOTIONS TO SUSPEND THE RULES ON TODAY

  Mrs. MORELLA. Madam Speaker, I ask unanimous consent that it be in 
order at any time today for the Speaker to entertain motions to suspend 
the rules and pass the following bills:
  H.R. 4884, H.R. 4534, H.R. 4615, H.R. 3454, H.R. 4484, H.R. 2302, 
H.R. 4448, and H.R. 4449.
  The SPEAKER pro tempore (Mrs. Biggert). Is there objection to the 
request of the gentlewoman from Maryland?
  There was no objection.
```
