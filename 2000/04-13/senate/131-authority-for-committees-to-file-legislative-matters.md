# AUTHORITY FOR COMMITTEES TO FILE LEGISLATIVE MATTERS

```
          AUTHORITY FOR COMMITTEES TO FILE LEGISLATIVE MATTERS

  Mr. SESSIONS. Mr. President, I ask unanimous consent that, 
notwithstanding the adjournment, the Senate committees have from 11 
a.m. until 1 p.m. on Thursday, April 20, in order to file legislative 
matters.
  The PRESIDING OFFICER. Without objection, it is so ordered.
```
