# MEASURE READ THE FIRST TIME--S.J. RES. 54

```
               MEASURE READ THE FIRST TIME--S.J. RES. 54

  Mr. REID. Mr. President, I understand that S.J. Res. 54, introduced 
earlier today by Senator Kennedy and others, is at the desk. I ask for 
its first reading.
  The PRESIDING OFFICER. The clerk will report the bill for the first 
time.
  The assistant legislative clerk read as follows:

       A joint resolution (S.J. Res. 54) expressing the sense of 
     Congress with respect to the peace process in Northern 
     Ireland.

  Mr. REID. I now ask for its second reading and object to my own 
request.
  The PRESIDING OFFICER. Objection is heard.
  Mr. LOTT addressed the Chair.
  The PRESIDING OFFICER. The majority leader.

                          ____________________
```
