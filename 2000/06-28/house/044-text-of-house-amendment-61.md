# Text of House Amendment 61

**Speaking:** Payne, Donald M. (P000149) [D-NJ]

**Measures:** H.R. 4461

```
H.R. 4461

                         Offered By: Mr. Payne

       Amendment No. 61: At the end of the bill (preceding the 
     short title) insert the following:


                 operation lifeline sudan (ols) program

       Sec. ____. The Administrator of the United States Agency 
     for International Development shall take appropriate action 
     to reform the Operation Lifeline Sudan (OLS) program so that 
     humanitarian assistance operations under the program function 
     properly.
```
