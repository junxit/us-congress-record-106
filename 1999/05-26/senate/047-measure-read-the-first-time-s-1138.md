# MEASURE READ THE FIRST TIME--S. 1138

```
                  MEASURE READ THE FIRST TIME--S. 1138

  Mr. GRASSLEY. Mr. President, a bill by Senators McCain and Dodd is at 
the desk. I ask that it be read the first time.
  The PRESIDING OFFICER. The clerk will report.
  The assistant legislative clerk read as follows:

       A bill (S. 1138) to regulate interstate commerce by making 
     provision for dealing with losses arising from Year 2000 
     Problem-related failures that may disrupt communications, 
     intermodal transportation, and other matters affecting 
     interstate commerce.

  Mr. GRASSLEY. I now ask for the second reading, and I object to my 
own request.
  The PRESIDING OFFICER. The objection is heard.
  The bill will be read for the second time on the next legislative 
day.

                          ____________________
```
