# ORDER PROVIDING FOR THE INTRODUCTION OF LEGISLATION AND STATEMENTS ON JANUARY 19, 1999

```
 ORDER PROVIDING FOR THE INTRODUCTION OF LEGISLATION AND STATEMENTS ON 
                            JANUARY 19, 1999

  Mr. LOTT. Mr. President, I ask unanimous consent that on January 19, 
1999, all Senators be permitted to introduce legislation and read or 
submit accompanying statements for the Record. This would represent the 
first day that legislation can be introduced in the 106th Congress.
  The PRESIDING OFFICER. Without objection, it is so ordered.

                          ____________________
```
